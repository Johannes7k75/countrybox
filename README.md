# Country Box

## 🛠️ Tech Stack
- **Go** (Backend)
- **Nuxt** (Frontend)
- **Goose** (Database Migration)
- **MySQL** (Database)

## 📜 Deployment
> [!WARNING]
> At the moment this deploy method is broken

Requirements:
- Docker
- Docker Compose

### Steps to Deploy
1. Clone the repository:
   ```bash
   git clone https://github.com/Johannes7k75/countrybox
   cd countrybox
   ```

2. Start the Docker containers:
   ```bash
   docker compose up -d --build
   ```
